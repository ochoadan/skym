## Failures found and corrected

The first server build failed because two framework namespaces exposed `BadHttpRequestException`; the handler now names the intended HTTP type explicitly. An independent reviewer reproduced an unhandled `InvalidDataException` during invalid-config startup and identified Web JSON defaults accepting quoted numbers. The startup handler now catches that exception explicitly and JSON number handling is strict. Process tests verify both corrections. Review also led to strict end-of-string ID validation, with a trailing-newline regression case. No unresolved functional failure remains from these checks.
